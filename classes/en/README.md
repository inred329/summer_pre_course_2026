# English Track Entry

This page remains as the entry for the English-taught preparatory track. Students do not need to begin with policy or maintenance documents.

The English preparatory track consists of five 2-hour sessions, totaling 10 hours, with terminology and learning support appropriate to students' language backgrounds.

## If you are taking the preparatory course

Start directly with the first Unit:

**[P-U00: How Does the C Code You Write Actually Start Running?](../../materials/preparatory/unit-00-compiler-ide.en.md)**

Reading order: P-U00 → P-U01 → P-U02 → P-U03 → P-U04

P-U00 first separates the roles of the compiler, IDE, Build, Run, and Debug before the later Units move into execution, data, control flow, and functions.

## If you later enter the formal course

If you did not complete this preparatory sequence, start the formal course with F-U00:

**[Start the formal course with F-U00](../../materials/formal/unit-00-build-run-ide.en.md)**

If you just completed P-U00 through P-U04, P-U00 has already built the tool model, so you do not need to immediately repeat F-U00. Continue directly with:

**[After preparatory, continue with F-U01](../../materials/formal/unit-01-representation-types.en.md)**

You can also return to the shared [Student Start page](../../materials/STUDENT-START.en.md) to see both valid formal-course entry paths.

## How learning works

The course builds understanding through prediction, tracing, implementation, testing, debugging, modification, and explanation. After entering the first Unit, use the “Next Unit” link at the end of each chapter to continue.
