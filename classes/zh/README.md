# 中文班入口

中文班以繁體中文授課，重要程式設計術語保留適當的中英文對照，協助學生銜接後續專業課程。

中文班共 4 堂，每堂 3 小時，共 12 小時。中文班與英文班維持相同的核心能力、技術深度與評量標準；多出的授課時間用於練習、討論、錯誤診斷與理解鞏固，不提高核心通過標準。

## 學習方式

課程先建立問題脈絡、概念與心智模型，再進入語法與程式。學生會透過預期、追蹤、實作、測試、除錯、修改與說明來建立能力。

作業是自主學習工具，不需繳交，也不直接計分。正式評量方式與可使用資源，以正式學習與評量制度及課程公告為準。
