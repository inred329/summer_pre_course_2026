# 中文班規劃

## 班級定位

以中文授課，重要專有名詞可保留中英文對照，協助學員銜接後續專業學習。

## 待確認

- 學員背景與先備能力
- 招生人數與分組方式
- 講師與助教
- 教材語言與範例情境
- 課前補充資料
