# 2026 大專暑期前導課程｜2026 Summer Preparatory Course

本倉庫用於規劃 2026 大專暑期前導課程，包含兩個班別：

This repository contains the planning and teaching materials for the 2026 Summer Preparatory Course, which includes two tracks:

- 中文班（Chinese-taught Class）
- 英文班（English-taught Class）

## 課程憲法｜Course Constitution

課程憲法是本倉庫的最高指導文件。繁體中文版與英文版具有同等效力，並須同步維護。

The Course Constitution is the highest governing document of this repository. The Traditional Chinese and English versions have equal authority and must be maintained together.

- [繁體中文版｜Traditional Chinese](CONSTITUTION.zh-TW.md)
- [English Version｜英文版](CONSTITUTION.en.md)

## 規劃原則｜Planning Principles

兩班共享核心學習目標、課程內容、難度與評量標準，僅依授課語言與必要的語言情境調整表達方式。

Both classes share the same core learning objectives, course content, difficulty, and assessment standards. Only the language of instruction and necessary language-specific presentation may differ.

所有正式文件均須同時提供繁體中文版與英文版。單一語言文件僅能視為未完成草稿，除非明確標示為內部暫存文件。

Every official document must be provided in both Traditional Chinese and English. A single-language document is considered an incomplete draft unless explicitly marked as a temporary internal document.

## 既有規劃結構｜Existing Planning Structure

- `docs/course-overview.md`：共用課程目標與設計決策
- `classes/zh/README.md`：中文班規劃
- `classes/en/README.md`：英文班規劃
- `planning/timeline.md`：籌備時程
- `planning/checklist.md`：執行檢查清單

上述既有文件後續須依課程憲法完成雙語化與一致性檢查。

The existing documents listed above must subsequently be made bilingual and reviewed for consistency under the Course Constitution.
