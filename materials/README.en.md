## Document Purpose

This directory provides materials, activities, exercises, acceptance resources, and instructor guidance that can be used directly in the Chinese preparatory class, English preparatory class, and formal course.

Every official material must:

- Be reachable from the root README and this index.
- Be available in both Traditional Chinese and English.
- Cite requirement IDs, competency IDs, maturity targets, scope states, and acceptance tasks.
- Follow the [Unit Material Template](TEMPLATE.en.md).
- Include reading, prediction, implementation, modification, testing, debugging, and explanation in the learning cycle.
- State specific permitted, prohibited, and retained evidence for AI use.

## Use Principles

The Chinese preparatory class may use Unit 1 in the first half to two-thirds of its first three-hour session. The English preparatory class delivers the same core competencies in Session 1. Both tracks use the same core evidence and passing criteria, while pacing, language scaffolding, and remediation may differ.
