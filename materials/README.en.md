### Formal course

If you are taking the formal course, you may start directly with F-U01. You do not need to complete the preparatory course first.

**[F-U01: Why Do Representation, Type, and Operations Affect Results?](formal/unit-01-representation-types.en.md)**

Reading order: F-U01 → F-U02 → F-U03 → F-U04 → F-U05 → F-U06 → F-U07 → F-U08 → F-U09 → F-U10 → F-U11 → F-U12

- [Complete F-U01–F-U12 formal-course index](formal/README.en.md)

If a basic idea feels unfamiliar during the formal course, review only the preparatory Unit you need. The preparatory course is not a fixed prerequisite reading path for formal-course students.

## How to continue through the materials

Each Unit ends with a link to the next Unit. In normal use, start with the first Unit and continue forward. You do not need to return to the repository home page or read the Course Constitution, design documents, review records, technical validation, or instructor documents in order to understand the student materials.
