# 前導教材舊評量措辭遷移說明

版本：2.0.0  
狀態：遷移說明；不具獨立規範效力  
主要讀者：教材維護者  
唯一權威來源：[學習與評量制度](../../design/13-learning-assessment-policy.zh-TW.md)  
對應英文版本：[Preparatory Assessment Wording Migration Note](ASSESSMENT-NOTE.en.md)

## 文件目的

本文件只協助維護者辨識前導教材中的舊評量措辭，並將其改寫為符合現行政策的文字。

本文件不得覆寫、補充或重新定義正式評量制度。若教材與正式政策不一致，應直接修正教材，並以 `design/13-learning-assessment-policy.zh-TW.md` 為準。

## 舊措辭遷移對照

| 舊教材措辭 | 修正方向 |
|---|---|
| 提交／繳交 | 改為學生自行保存，除非正式政策另有規定。 |
| 必要證據 | 改為有助於學習、討論或口試準備的個人學習紀錄。 |
| 通過判準 | 改為自我檢核或能力目標，不形成單份作業成績。 |
| 補驗 | 改為形成性補救或再練習，不暗示每份作業都有正式補考。 |
| 微型口試 | 改為課堂形成性追問，不描述為獨立計分口試。 |
| AI 使用紀錄 | 移除普遍強制要求；使用 AI 時，學生仍須能解釋與驗證採用內容。 |
| 未使用 AI 聲明 | 刪除。未使用 AI 不構成能力缺失。 |

## 維護原則

發現舊措辭時，不應長期依賴本文件提供「優先解釋」，而應直接修改原教材，使學生只讀到現行且一致的規則。

本文件完成遷移任務後，可以降級為歷史紀錄或刪除。
