# 前導教材評量制度補充規則

版本：1.0.0  
狀態：正式優先規則  
最後更新：2026-08-03  
重大變更摘要：統一覆蓋舊教材中與現行制度衝突的「提交、逐份評分、補驗、微型口試」措辭。  
對應英文版本：[Preparatory Material Assessment Override](ASSESSMENT-NOTE.en.md)

## 適用範圍

本規則適用於 `materials/preparatory/` 下所有前導單元教材。當單元教材中的舊措辭與本文件、`design/13-learning-assessment-policy` 或 `design/07-acceptance-model` 衝突時，以本文件與設計基準為準。

## 正式解釋

| 舊教材措辭 | 現行正式解釋 |
|---|---|
| 提交／繳交 | 學生自行保存，無須交給教師逐份批改。 |
| 必要證據 | 學生應自行建立並保留的學習紀錄，可用於下堂討論與最終口試準備。 |
| 通過判準 | 自我檢核與能力目標，不構成單份作業成績。 |
| 補驗 | 課堂中的針對性補救活動，不是每份作業後的正式補考。 |
| 微型口試 | 課堂形成性追問，不是獨立計分口試；正式口試只有期末一次一對一口試。 |
| 驗收任務 `AT-12` | 只指一次最終一對一口試。 |

## 現行制度

- 每次課後都有自主作業。
- 作業不繳交、不計分、不逐份批改。
- 下一堂課保留 15–25 分鐘討論前次作業。
- 課堂追問、追蹤、測試與除錯是形成性學習活動。
- 課堂參與與一次最終一對一口試構成正式成績。
- 不以點名、出席率或發言次數計分。

## 學生應自行保存

- 程式與不同版本。
- 執行前預測。
- 測試與預期結果。
- 狀態或流程追蹤。
- 錯誤、修正與回歸結果。
- AI 使用與驗證紀錄。
