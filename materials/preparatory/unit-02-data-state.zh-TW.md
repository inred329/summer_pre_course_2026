## 文件用途與完成標準

這是一份供初學者獨立閱讀、練習與複習的學生教材。完成本章不只是讓程式輸出正確，而是能解釋值、型別、變數與狀態的關係，能逐步追蹤指定造成的改變，並能用測試證明修改後的程式仍符合需求。

本章活動不需繳交；請自行保存預測、狀態表、程式、測試與修正紀錄。

## 這一章要回答什麼？

上一章中，程式只輸出固定文字。真正的程式必須保存資料、更新資料，並依目前資料得到新的結果。

> 程式如何保存目前的資料，並在每一步執行後產生新的狀態？

完成本章後，你應能：

1. 區分資料、值、型別、變數名稱與目前值。
2. 追蹤初始化、指定與運算式造成的狀態改變。
3. 區分整數與浮點運算的基本差異。
4. 建立簡單的輸入、處理與輸出流程。
5. 在使用變數前檢查輸入是否成功。
6. 在需求修改後更新預期結果與測試。

前置知識：能建立、編譯並執行最小 C 程式，並在執行前寫下預期輸出。

---

## 1. 先預測狀態

```c
int score = 80;
score = score + 5;
printf("%d\n", score);
```

在執行前回答：

1. 第一行之後 `score` 是多少？
2. 第二行右側的 `score` 代表舊值還是新值？
3. 第二行執行完後，舊值還存在嗎？
4. 最後輸出什麼？

---

## 2. 五個核心概念

### 資料（data）

程式處理的資訊，例如成績、溫度或字元。

### 值（value）

某一刻實際存在的內容，例如 `80`、`3.5` 或 `'A'`。

### 型別（type）

型別決定資料如何表示，以及哪些運算可以套用。常見基本型別：

```c
int count = 5;
double temperature = 23.5;
char grade = 'A';
```

### 變數（variable）

變數用名稱指向目前保存的值。名稱不是值本身；同一個名稱在不同時間可以保存不同值。

### 狀態（state）

某一時刻所有重要變數目前值的集合。

---

## 3. 狀態改變模型

```mermaid
flowchart LR
    O[舊狀態] --> E[運算式求值]
    E --> A[指定]
    A --> N[新狀態]
    N --> P[輸出或下一步]
```

對這行程式：

```c
score = score + 5;
```

可以拆成：

```text
讀取右側舊值 80
→ 計算 80 + 5
→ 得到 85
→ 把 85 寫回左側 score
```

---

## 4. 最小可執行範例

```c
#include <stdio.h>

int main(void) {
    int score = 80;
    score = score + 5;
    printf("%d\n", score);
    return 0;
}
```

預期輸出：

```text
85
```

狀態追蹤：

| 步驟 | 敘述 | 執行前 `score` | 運算結果 | 執行後 `score` |
|---|---|---:|---:|---:|
| 1 | `int score = 80;` | 尚不存在 | 80 | 80 |
| 2 | `score = score + 5;` | 80 | 85 | 85 |
| 3 | `printf(...)` | 85 | 85 | 85 |

---

## 5. 初始化與指定不是同一件事

初始化在變數建立時給初始值：

```c
int score = 80;
```

指定在變數已存在後更新值：

```c
score = 90;
```

`=` 在 C 中表示指定，不是數學等號。左側指出要被更新的位置，右側先被求值。

## 6. 輸入、處理與輸出

```c
#include <stdio.h>

int main(void) {
    int score;

    if (scanf("%d", &score) != 1) {
        fprintf(stderr, "Invalid input\n");
        return 1;
    }

    score = score + 5;
    printf("Adjusted score: %d\n", score);

    return 0;
}
```

本章暫時把 `&score` 視為「讓 `scanf` 能把輸入寫入 `score` 的形式」；指標意義會在後續 Unit 學習。

`scanf` 會回報成功讀入的資料數量。程式必須先檢查結果再使用 `score`；否則輸入失敗時，變數可能沒有可用的有效值。

測試：

| 輸入 | 預期結果 |
|---:|---|
| 80 | `Adjusted score: 85` |
| 0 | `Adjusted score: 5` |
| -5 | `Adjusted score: 0` |
| `abc` | 顯示錯誤訊息並以非零狀態結束 |

---

## 7. 錯誤案例一：整數除法

```c
int total = 5;
int count = 2;
double average = total / count;
printf("%.1f\n", average);
```

先預測輸出。結果是：

```text
2.0
```

原因是 `total / count` 的兩個運算元都是 `int`，所以先做整數除法得到 `2`，之後才轉成 `double`。

修正：

```c
double average = (double) total / count;
```

驗證案例：`5/2`、`4/2`、`1/2`。

---

## 8. 錯誤案例二：格式與型別不一致

```c
int score = 80;
printf("%f\n", score);
```

`%f` 預期的是浮點值，但 `score` 是 `int`。這種不一致會造成未定義行為。請使用編譯器警告作為診斷證據，而不是只看偶然出現的畫面結果。

正確形式：

```c
printf("%d\n", score);
```

常用對應：

| 型別 | `printf` | `scanf` |
|---|---|---|
| `int` | `%d` | `%d` |
| `double` | `%f` | `%lf` |
| `char` | `%c` | `%c` |

## 10. 自主練習：成績調整器

