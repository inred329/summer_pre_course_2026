## Start Here

These four Units form the preparatory C programming path. Read them in order unless an instructor directs you to revisit a specific prerequisite.

1. [P-U01 — Execution and Translation](unit-01-execution.en.md)
2. [P-U02 — Data, Values, and State](unit-02-data-state.en.md)
3. [P-U03 — Control Flow](unit-03-control-flow.en.md)
4. [P-U04 — Functions and Integration](unit-04-functions-integration.en.md)

Each Unit keeps the core learning path independent of AI or another external assistant. Optional external-assistance extensions may be skipped without affecting Unit completion, participation, or assessment.
