## 核心問題

> 電腦如何把文字保存成資料，又如何知道文字在哪裡結束？

完成本章後，你應能：

1. 區分字元、字元陣列與 C 字串。
2. 說明空字元 `\0` 的角色。
3. 使用 `fgets` 安全讀取一行文字。
4. 區分完整讀入與被緩衝區截斷的輸入行。
5. 走訪與測量字串。
6. 診斷缺少終止符、容量不足、殘留換行與殘留輸入。

---

## 1. 字串其實是一組字元

```c
char word[] = "cat";
```

記憶體概念：

```text
索引:   0    1    2    3
內容:  'c'  'a'  't' '\0'
```

C 字串沒有獨立的內建字串型別；它通常是以空字元結尾的 `char` 陣列。

---

## 2. 終止符決定文字在哪裡結束

```c
char letters[3] = {'c', 'a', 't'};
```

這是一個字元陣列，但不是可靠的 C 字串，因為沒有空字元。

```c
char word[4] = {'c', 'a', 't', '\0'};
```

字串函式會從第一個元素開始讀取，直到遇到 `\0`。

---

## 3. 字串長度與陣列容量不同

```c
char name[20] = "Amy";
```

- 陣列容量：20 個 `char`
- 字串長度：3
- 實際需要：`'A'`、`'m'`、`'y'`、`'\0'`

容量必須能容納文字與終止符。

---

## 4. 使用 `fgets` 讀取一行

```c
#include <stdio.h>

int main(void) {
    char name[20];

    if (fgets(name, sizeof name, stdin) == NULL) {
        fprintf(stderr, "Input failed.\n");
        return 1;
    }

    printf("Hello, %s", name);
    return 0;
}
```

`fgets` 最多讀入容量減一個字元，成功時一定補上 `\0`。若輸入行可完整容納，換行字元通常也會保存；若輸入行過長，緩衝區只保存前半段，剩餘字元仍留在輸入資料流中。

---

## 5. 移除換行並判斷截斷

```c
#include <stdio.h>
#include <string.h>

int read_line(char text[], size_t capacity) {
    if (text == NULL || capacity == 0) {
        return 0;
    }

    if (fgets(text, capacity, stdin) == NULL) {
        return 0;
    }

    size_t newline = strcspn(text, "\n");
    if (text[newline] == '\n') {
        text[newline] = '\0';
        return 1;
    }

    int ch;
    while ((ch = getchar()) != '\n' && ch != EOF) {
        /* 丟棄過長輸入行的剩餘字元 */
    }

    return 0;
}
```

回傳規則：

- `1`：完整讀入一行，並已移除換行。
- `0`：參數無效、讀取失敗，或輸入行超過緩衝區。

丟棄剩餘字元可避免下一次輸入誤讀同一行尚未讀完的內容。

測試：

- 空行
- 短文字
- 剛好 `capacity - 2` 個可見字元再加換行
- 超過緩衝區的長行
- 尚未讀到任何字元就遇到 EOF

---

## 6. 手動走訪字串

```c
int length = 0;
while (name[length] != '\0') {
    length++;
}
```

追蹤 `"Amy"`：

| 索引 | 字元 | 是否結束 |
|---:|---|---|
| 0 | `A` | 否 |
| 1 | `m` | 否 |
| 2 | `y` | 否 |
| 3 | `\0` | 是 |

---

## 7. 常用字串函式

```c
strlen(text)
strcmp(a, b)
strcpy(destination, source)
```

使用前必須確認：

- 輸入確實有終止符
- 目的陣列容量足夠
- 不把 `strcmp` 的回傳值誤解成布林「相等」

字串相等應寫：

```c
if (strcmp(a, b) == 0) {
    /* equal */
}
```

## 8. 錯誤案例

### 使用 `==` 比較字串

```c
if (a == b)
```

這比較的是位址或轉換後的指標值，不是字串內容。應使用 `strcmp`。

### 緩衝區太小

```c
char word[3] = "cat";
```

沒有空間容納 `\0`，至少需要 4 個元素。編譯器應對這個初始化提出診斷。

### 假設 `fgets` 一定讀完整行

`fgets` 成功只保證緩衝區內有終止符，不代表完整邏輯輸入行已讀完。若沒有換行且緩衝區已滿，應判斷是否截斷，並在下一次輸入前清除殘留字元。

## 10. 自主練習：文字分析器

讀入一個完整輸入行，輸出：

- 字串長度
- 空白數量
- 數字字元數量
- 第一個字元與最後一個字元（若非空字串）

測試空行、短文字、剛好可完整容納、過長輸入與包含空白的文字。不得在輸入被截斷時默默只分析前半段。
