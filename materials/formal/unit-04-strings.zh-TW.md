## 文件用途與完成標準

本章供學生獨立閱讀、練習與複習。完成本章代表你能說明 C 字串如何以字元陣列與空字元表示，能安全讀取與走訪字串，並能診斷終止符、緩衝區與格式相關錯誤。

## 核心問題

> 電腦如何把文字保存成資料，又如何知道文字在哪裡結束？

完成本章後，你應能：

1. 區分字元、字元陣列與 C 字串。
2. 說明空字元 `\0` 的角色。
3. 使用 `fgets` 安全讀取一行文字。
4. 走訪與測量字串。
5. 診斷缺少終止符、緩衝區不足與殘留換行。

---

## 1. 字串其實是一組字元

```c
char word[] = "cat";
```

記憶體概念：

```text
索引:   0    1    2    3
內容:  'c'  'a'  't' '\0'
```

C 字串沒有獨立的內建字串型別；它通常是以空字元結尾的 `char` 陣列。

---

## 2. 終止符決定文字在哪裡結束

```c
char letters[3] = {'c', 'a', 't'};
```

這是一個字元陣列，但不是可靠的 C 字串，因為沒有空字元。

```c
char word[4] = {'c', 'a', 't', '\0'};
```

字串函式會從第一個元素開始讀取，直到遇到 `\0`。

---

## 3. 字串長度與陣列容量不同

```c
char name[20] = "Amy";
```

- 陣列容量：20 個 `char`
- 字串長度：3
- 實際需要：`'A'`, `'m'`, `'y'`, `'\0'`

容量必須能容納文字與終止符。

---

## 4. 使用 `fgets` 讀取一行

```c
#include <stdio.h>

int main(void) {
    char name[20];

    if (fgets(name, sizeof name, stdin) != NULL) {
        printf("Hello, %s", name);
    }

    return 0;
}
```

`fgets` 最多讀入容量減一個字元，保留空間放 `\0`。若輸入行未超出容量，換行字元通常也會被保存。

---

## 5. 移除殘留換行

```c
#include <string.h>

name[strcspn(name, "\n")] = '\0';
```

`strcspn` 找到第一個換行的位置；若不存在換行，會得到字串長度。這行程式把換行改成終止符。

---

## 6. 手動走訪字串

```c
int length = 0;
while (name[length] != '\0') {
    length++;
}
```

追蹤 `"Amy"`：

| 索引 | 字元 | 是否結束 |
|---:|---|---|
| 0 | `A` | 否 |
| 1 | `m` | 否 |
| 2 | `y` | 否 |
| 3 | `\0` | 是 |

---

## 7. 常用字串函式

```c
strlen(text)
strcmp(a, b)
strcpy(destination, source)
```

使用前必須確認：

- 輸入確實有終止符
- 目的陣列容量足夠
- 不把 `strcmp` 的回傳值誤解成布林「相等」

字串相等應寫：

```c
if (strcmp(a, b) == 0) {
    /* equal */
}
```

---

## 8. 錯誤案例

### 使用 `==` 比較字串

```c
if (a == b)
```

這比較的不是字串內容。使用 `strcmp`。

### 緩衝區太小

```c
char word[3] = "cat";
```

沒有空間容納 `\0`。至少需要 4。

### 假設 `fgets` 不會保留換行

輸出時可能多出空行或格式不如預期。先觀察實際陣列內容，再移除換行。
