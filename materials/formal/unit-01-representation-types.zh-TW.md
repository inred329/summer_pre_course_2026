# 正式單元 F-U01：表示、型別與運算為什麼會影響結果？

## 文件用途與完成標準

本章供學生獨立閱讀、練習與複習。完成本章代表你能說明同一組位元如何因型別與解讀方式產生不同意義，能預測轉型與運算結果，並能用測試診斷溢位、整數除法與浮點誤差。

## 核心問題

> 同一個數值或運算，為什麼可能因表示方式與型別而產生不同結果？

完成本章後，你應能：

1. 區分值、表示與型別。
2. 說明位元、MSB 與 LSB 的位置意義。
3. 預測整數除法、轉型與格式化輸出。
4. 說明浮點數不是所有實數的精確表示。
5. 用邊界案例與容許誤差測試結果。

---

## 1. 先看一組位元

```text
10110010
```

在沒有額外資訊時，它可能代表無號整數、有號整數、字元編碼的一部分，或其他格式。位元本身只有 0 與 1；型別與規則賦予它意義。

---

## 2. MSB 與 LSB

對一個固定位數的位元序列：

```text
1 0 1 1 0 0 1 0
^             ^
MSB           LSB
```

- MSB（Most Significant Bit）：權重最高、最左側的位元。
- LSB（Least Significant Bit）：權重最低、最右側的位元。

在無號二進位整數中，LSB 的權重是 1，向左每一位權重乘 2。MSB 只是位置名稱；在不同表示法中，它可能具有不同角色。

---

## 3. 型別決定解讀與可用操作

```c
unsigned int count = 10;
int change = -3;
double ratio = 0.5;
char letter = 'A';
```

型別影響：

- 可表示範圍
- 儲存方式
- 運算規則
- 格式化輸入輸出
- 轉型行為

不要把「型別」只理解成變數前面的關鍵字；它是一組解讀與操作規則。

---

## 4. 整數除法與轉型

```c
int a = 5;
int b = 2;
double x = a / b;
double y = (double)a / b;
```

預測：

```text
x = 2.0
y = 2.5
```

`a / b` 先依兩個 `int` 做整數除法；把結果存進 `double` 不會補回已丟失的小數。顯式轉型改變運算前的型別。

---

## 5. 浮點表示與誤差

```c
#include <stdio.h>

int main(void) {
    double x = 0.1 + 0.2;
    printf("%.17f\n", x);
    return 0;
}
```

結果可能接近但不完全等於 `0.3`。許多十進位小數無法用有限二進位位數精確表示。

因此不應直接以：

```c
x == 0.3
```

判斷所有浮點結果。可使用容許誤差：

```c
#include <math.h>

if (fabs(x - 0.3) < 1e-9) {
    printf("close enough\n");
}
```

---

## 6. 整數範圍與溢位

型別的可表示範圍有限。可以使用：

```c
#include <limits.h>

printf("%d\n", INT_MAX);
```

不要靠猜測固定範圍。對有號整數，超出範圍可能導致未定義行為；不能把觀察到的一次結果當成保證。

測試接近邊界的值，並先寫出你認為應採取的防護策略。

---

## 7. 字元也是資料表示

```c
char c = 'A';
printf("%c %d\n", c, c);
```

同一個 `char` 可依格式被顯示為字元或整數編碼。這不表示它同時是兩個值，而是同一資料以不同方式呈現。

---

## 8. 錯誤案例

### 錯誤一：以為儲存型別會改變先前運算

```c
double average = total / count;
```

應檢查運算元型別，而不是只看左側。

### 錯誤二：浮點數直接相等比較

使用一組計算產生的值與字面常數比較，改用誤差範圍。

### 錯誤三：格式字串不匹配

```c
printf("%d\n", 3.14);
```

使用編譯器警告與型別表診斷。

---

## 9. 引導練習

1. 將 8 位元 `00101101` 由 LSB 向 MSB 標出權重並計算無號值。
2. 預測 `7 / 3`、`7.0 / 3`、`(double)7 / 3`。
3. 比較 `0.1 + 0.2` 與 `0.3`，使用誤差判斷。

## 14. 本章摘要

資料的位元表示必須配合型別與規則才有意義。運算結果取決於運算元型別，轉型時機會改變結果，浮點數需要以近似與誤差思考。下一章將把這些判斷放進更複雜的控制流程。
