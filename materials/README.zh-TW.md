## 文件目的

本目錄提供可直接用於中文與英文前導班的教材、活動、練習、作業、驗收及教師執行資源。

所有正式教材必須：

- 由根 README 與本索引抵達。
- 同時提供繁體中文與英文版本。
- 引用需求 ID、能力 ID、成熟度、範圍狀態與驗收任務。
- 依 [單元教材模板](TEMPLATE.zh-TW.md) 建立。
- 將閱讀、預測、實作、修改、測試、除錯與說明納入學習循環。
- 明確說明 AI 允許、禁止與必須保留的證據。
