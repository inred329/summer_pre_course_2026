### 正式課程

如果你現在上的是正式課程，從 F-U00 開始，不需要先讀完前導課程。

**[F-U00：按下 Run 之後，到底發生了什麼？](formal/unit-00-build-run-ide.zh-TW.md)**

閱讀順序：F-U00 → F-U01 → F-U02 → F-U03 → F-U04 → F-U05 → F-U06 → F-U07 → F-U08 → F-U09 → F-U10 → F-U11 → F-U12

- [正式課程 F-U00～F-U12 完整索引](formal/README.zh-TW.md)

F-U00 不是要求正式班重上前導課程，而是先把正式課程會持續使用的 source、compiler、Build、Run、Debug 等工具角色拆清楚。若之後遇到其他不熟悉的基礎概念，再依需要回到前導 Unit 複習即可。

## 怎麼沿著教材讀下去

每個 Unit 的結尾都有下一單元連結。正常情況下，從 U00 開始一路往下即可，不需要回到 repository 首頁，也不需要閱讀課程憲法、設計文件、審查紀錄、技術驗證或教師文件才能理解教材。
