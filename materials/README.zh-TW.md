### 正式課程

如果你現在上的是正式課程，可以直接從 F-U01 開始，不需要先讀完前導課程。

**[F-U01：表示、型別與運算為什麼會影響結果？](formal/unit-01-representation-types.zh-TW.md)**

閱讀順序：F-U01 → F-U02 → F-U03 → F-U04 → F-U05 → F-U06 → F-U07 → F-U08 → F-U09 → F-U10 → F-U11 → F-U12

- [正式課程 F-U01～F-U12 完整索引](formal/README.zh-TW.md)

如果你在正式課程中遇到不熟悉的基本概念，再依需要回到前導 Unit 複習即可；前導課程不是正式班學生的固定前置閱讀清單。

## 自主練習

前導課程另有自主作業與口試準備材料：

- [自主作業與口試準備包](assignments/preparatory-assignments.zh-TW.md)

## 怎麼沿著教材讀下去

每個 Unit 的結尾都有下一單元連結。正常情況下，從第一個 Unit 開始一路往下即可，不需要回到 repository 首頁，也不需要閱讀課程憲法、設計文件、審查紀錄、技術驗證或教師文件才能理解教材。
