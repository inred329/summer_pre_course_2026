## 文件目的

本目錄提供可直接用於中文前導班、英文前導班與正式課程的教材、活動、練習、驗收及教師執行資源。

所有正式教材必須：

- 由根 README 與本索引抵達。
- 同時提供繁體中文與英文版本。
- 引用需求 ID、能力 ID、成熟度、範圍狀態與驗收任務。
- 依 [單元教材模板](TEMPLATE.zh-TW.md) 建立。
- 將閱讀、預測、實作、修改、測試、除錯與說明納入學習循環。
- 明確說明 AI 允許、禁止與必須保留的證據。

## 使用原則

中文前導班可將第一單元安排為第 1 堂的前半至三分之二；英文前導班將相同核心能力安排於 Session 1。兩班的核心證據與通過標準相同，但時間切分、語言支架與補救節奏可以不同。
