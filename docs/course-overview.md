- 日期：待定

## 目標學員

待定義：年級、科系背景、語言能力、先備知識與設備需求。

## 共同學習目標

完成課程後，學員應能：

1. 理解課程主題的核心概念
2. 完成指定的實作或專題任務
3. 清楚說明成果、方法與反思
4. 知道後續自學方向與可用資源

## 兩班一致項目

- 核心學習目標
- 單元主題與總時數
- 作業與評量標準
- 學習成果與品質門檻
- 課前、課中及課後問卷

## 兩班可調整項目

- 授課語言與術語呈現
- 教材案例與文化情境
- 學習鷹架與補充資源
- 討論、提問及分組活動方式
