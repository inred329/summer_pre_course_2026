# 課程籌備與開課檢查清單

版本：0.2.0  
狀態：現行操作清單  
最後更新：2026-08-07  
主要讀者：授課教師、助教、行政與課程維護者  
規範效力：本文件只追蹤操作準備，不自行建立課程範圍、評量、完課或 AI／工具政策

## 使用原則

- 課程能力、範圍與交付內容不得由本清單重新定義；請依 [design 治理索引](../design/README.zh-TW.md) 使用現行權威來源。
- 作業、課堂參與、出席、成績、最終口試與 AI／工具規則只以[正式學習與評量制度](../design/13-learning-assessment-policy.zh-TW.md)為準。
- 中文班與英文班的核心能力、技術深度與評量期待必須實質等值；授課節奏與語言支架可依[交付地圖](../design/08-delivery-map.zh-TW.md)調整。
- 勾選代表操作條件已確認，不代表學生能力已被驗收，也不構成新的政策。

## 課程與教材準備

- [ ] 確認目前授課版本引用 Constitution 2.0 與現行正式政策。
- [ ] 確認中文班 4 × 3 小時與英文班 5 × 2 小時的實際日期、時段與場地／線上資訊。
- [ ] 依交付地圖確認每一堂的 Unit／Lesson 切分、緩衝與備援活動。
- [ ] 確認學生入口、教材索引、前導 Unit 與正式課程銜接連結可用。
- [ ] 抽樣核對中英文教材的核心問題、技術契約、測試與完成路徑實質等值。
- [ ] 以目前 CI／驗證結果確認 C17 範例、連結與雙語配對沒有未處理失敗。
- [ ] 針對實際教室機器記錄 GCC／Clang 或其他指定工具鏈版本與必要差異。
- [ ] 準備無網路、投影故障、帳號問題或編譯環境異常時的替代活動。

## 教學團隊

- [ ] 確認中文班講師、助教與替補／支援安排。
- [ ] 確認英文班講師、助教與替補／支援安排。
- [ ] 確認行政與技術支援窗口，以及課中緊急聯絡方式。
- [ ] 讓授課團隊知道學生文件、教師文件、正式政策與歷史紀錄的邊界。
- [ ] 確認教師與助教不把選用 AI／外部工具活動轉成普遍必做或參與門檻。

## 學生與可近用性支援

- [ ] 發送上課時間、地點／連結、設備與必要軟體等課前資訊。
- [ ] 蒐集教學上確實需要的先備、語言、設備與可近用性需求，避免蒐集與教學無關的資料。
- [ ] 準備多種課堂參與方式，避免把公開發言或固定互動形式當成唯一證據。
- [ ] 確認中文與英文班都能取得等值的核心教材、測試案例與補充支架。

## 場地與技術

- [ ] 確認教室／線上會議環境、網路、投影、電源與必要設備。
- [ ] 在實際學生環境測試編譯器、終端機、檔案權限與執行方式。
- [ ] 確認範例與缺陷案例依 `examples/COMPILE-MANIFEST.md` 的分類使用；不可把刻意 UB／非終止案例當普通自動執行測試。
- [ ] 準備離線教材或可在網路中斷時完成的核心活動。

## 評量與教學紀錄邊界

- [ ] 授課團隊已閱讀正式學習與評量制度，不從本清單另訂評分或完課規則。
- [ ] 自主作業的使用方式與正式政策一致，不自行改成普遍繳交／逐份計分要求。
- [ ] 課堂紀錄只保留教學與能力追蹤所需的最少資訊，不把出席次數、AI 使用紀錄或固定對話紀錄當成能力本身。
- [ ] 若學生實際採用外部協助，只在相關活動需要時檢查其理解、修改與技術驗證，而不是要求所有人提供使用或未使用聲明。

## 課後改善

- [ ] 記錄教材中造成理解困難、技術誤解或雙語不等值的具體位置。
- [ ] 記錄範例、工具鏈或 CI 出現的新失敗條件與重現方式。
- [ ] 將政策／治理問題回到正確權威文件處理；將教材問題更新到對應雙語 pair。
- [ ] 將重大治理修正記錄於 [Constitution 2.0 全庫審查](../reviews/repository-constitution-2-audit.zh-TW.md)。
- [ ] 將下一期改善事項區分為必要修正、教學實驗與一般優化，避免未驗證想法直接升級成正式要求。
