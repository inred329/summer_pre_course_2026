# 課程籌備檢查清單

## 課程設計

- [ ] 確認共同學習目標

- [ ] 排定單元與時數
- [ ] 設計實作、作業與評量規準
- [ ] 定義完課標準

## 人員

- [ ] 確認中文班講師與助教
- [ ] 確認英文班講師與助教
- [ ] 確認行政與技術支援窗口
- [ ] 建立聯絡與緊急應變方式

## 教材

- [ ] 完成中文班教材
- [ ] 完成英文班教材

## 招生與學員支援

- [ ] 完成招生文案與報名表
- [ ] 蒐集先備能力及語言需求
- [ ] 發送課前通知與準備事項

## 場地與技術

- [ ] 確認教室或線上會議空間
- [ ] 確認網路、投影、錄音錄影及電源

## 成效與結案
