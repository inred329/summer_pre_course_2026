# 籌備時程

以下以開課日為 T 日倒推，實際日期確認後再換成日曆日期。

| 時間 | 里程碑 | 主要產出 |
|---|---|---|
| T-12～10 週 | 定義課程 | 目標、對象、形式、時數、預算 |
| T-10～8 週 | 組成團隊 | 講師、助教、行政窗口與分工 |
| T-8～6 週 | 完成課綱 | 兩班課綱、單元、活動與評量 |
| T-6～4 週 | 製作教材 | 講義、投影片、實作、作業與規準 |
| T-4～3 週 | 招生與盤點 | 名單、背景問卷、設備與語言需求 |
| T-3～2 週 | 試教與修訂 | 試教紀錄、問題清單與教材修訂 |
| T-2～1 週 | 行前確認 | 通知、教室／會議連結、帳號與備援 |
| T | 正式開課 | 出席、教學紀錄、即時問題處理 |
| T+1 週 | 成效檢討 | 問卷、成果、完課資料與改善事項 |
