## 目前正式評量制度

- 每次課後都有自主作業，但不繳交、不計分、不逐份批改。
- 下一堂課保留 15–25 分鐘討論前次作業。
- 課堂參與不是出席率或發言次數，允許口頭與非口頭參與。
- 不點名計分。
- 正式成績只由課堂參與與一次最終一對一口試構成。
- 建議比例範圍：課堂參與 20–30%，最終口試 70–80%。
- 最終口試內容與流程將另立正式雙語文件。

## 核心原則

- C 是教學語言，核心目標是可遷移的程式設計能力。
- 教材依「需求 → 設計目的 → 語言邏輯 → 語法 → 實作 → 驗證」展開。
- 閱讀、預測、修改、測試、除錯、解釋與 AI 驗證同等重要。
- 每個單元應刻意提供可犯錯、可診斷、可修正的學習機會。
- 進階資料結構不預設為前導課程核心。
- 中英文班使用相同能力、難度與評量標準，只調整節奏與語言支架。
